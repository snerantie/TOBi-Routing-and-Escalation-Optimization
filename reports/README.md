# Executive charts

Management-ready visuals for the TOBi routing & escalation analysis. Generated by
[`build_exec_charts.py`](build_exec_charts.py).

> The PNGs currently in `figures/` were rendered from **deterministic illustrative
> data** so the layout and story are reviewable immediately. They are watermarked
> "ILLUSTRATIVE DATA". Re-run the script once the `models/` views exist on real
> data to replace them with live numbers (the watermark disappears automatically).

## Regenerate from live data

```bash
pip install google-cloud-bigquery pandas db-dtypes matplotlib
gcloud auth application-default login        # or set GOOGLE_APPLICATION_CREDENTIALS
python reports/build_exec_charts.py
```

The script reads `vf-pt-copsvertex-live.tobi_routing_analysis.v_session_master`.
Override location with env vars `TOBI_PROJECT` / `TOBI_ANALYSIS_DS`.
Force the illustrative dataset with `TOBI_USE_SYNTHETIC=1`.

## Executive dashboard layout

A single page with:
- **KPI cards**: technical sessions, % misrouted, technical FCR, recoverable agent-hours
- Misrouting by topic, average handling time, misroute % by confidence
- End-to-end funnel, repeat-contact comparison, misroute % by channel

## Design notes
- Consistent palette: red = problem/misroute, green = resolved, blue = correct route.
- Every chart carries a footnote stating the data source (or the illustrative
  watermark) for governance.
